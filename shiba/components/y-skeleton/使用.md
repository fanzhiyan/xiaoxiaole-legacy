#### 1. 简单使用
```vue
<template>
  <div>
    <!-- 其他内容 -->
    <SkeletonScreen :loading="isLoading" />
  </div>
</template>

<script setup>
import { ref } from 'vue';
import SkeletonScreen from './path/to/SkeletonScreen.vue'; // 根据实际路径调整

const isLoading = ref(true);

// 模拟数据加载
setTimeout(() => {
  isLoading.value = false;
}, 3000);
</script>
```


#### 2. 页面使用组件

在页面或组件中使用 `<SkeletonScreen />` 标签，并传递 `loading` 属性来控制骨架屏的显示。

```markdown
```vue
<template>
  <div>
    <!-- 其他内容 -->
    <SkeletonScreen :loading="isLoading" />
  </div>
</template>

```



#### 3. 自定义骨架屏元素

在需要显示骨架屏的地方，添加相应的类名 `skeleton-contaion`、`skeleton-row` 和 `skeleton-circle` 来标记矩形和圆形元素。

```markdown
```vue
<template>
  <div>
    <SkeletonScreen :loading="isLoading" />
    
    <div class="skeleton-contaion">
      <!-- 矩形骨架屏元素 -->
      <div class="skeleton-row" v-if="isLoading"></div>
      <div class="skeleton-row" v-if="isLoading"></div>
      
      <!-- 圆形骨架屏元素 -->
      <div class="skeleton-circle" v-if="isLoading"></div>
    </div>
    
    <!-- 实际内容 -->
    <div v-if="!isLoading">
      <p>实际内容加载完成后显示</p>
    </div>
  </div>
</template>

```




#### 4. 自定义样式

可以根据需要调整骨架屏元素的样式，例如宽度、高度、圆角等。

```markdown
```scss
.skeleton-row {
  width: 100%;
  height: 20px;
  margin-bottom: 10px;
  background-color: #e0e0e0;
}

.skeleton-circle {
  width: 50px;
  height: 50px;
  border-radius: 50%;
  background-color: #e0e0e0;
}
```
