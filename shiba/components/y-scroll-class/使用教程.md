### `ScrollList` 组件 `props` 参数说明

| 参数名              | 类型       | 默认值                  | 描述                                                                 |
|-------------------|----------|-----------------------|--------------------------------------------------------------------|
| list              | Array    | `[]`                  | 项目列表，每个项目是一个包含 `name` 和 `url` 属性的对象。                                     |
| heightNum         | Number   | `2`                   | 每页显示的行数。                                                                 |
| pageNum           | Number   | `10`                  | 每页显示的项目总数。                                                                |
| imgSize           | String   | `'50rpx'`             | 图标的大小，可以是数字或带单位的字符串。默认单位为 `rpx`。                                      |
| indicatorActiveColor | String | `'var(--l-color-theme)'` | 指示器激活颜色。默认使用主题颜色变量。                                                 |

### 使用组件示例

```html
<template>
  <div>
    <scroll-list
      :list="items"
      :heightNum="3"
      :pageNum="12"
      :imgSize="60"
      indicatorActiveColor="#009688"
    />
  </div>
</template>

<script>
import ScrollList from '@/components/ScrollList.vue';

export default {
  components: {
    ScrollList
  },
  data() {
    return {
      items: [
        { name: '项目1', url: 'https://example.com/icon1.png' },
        { name: '项目2', url: 'https://example.com/icon2.png' },
        // 更多项目...
      ]
    };
  }
};
</script>

<style scoped>
/* 这里可以添加自定义样式 */
</style>
```

### 注意事项

- **数据格式**：确保 `list` 中的每一个元素都是一个对象，且至少包含 `name` 和 `url` 两个属性(传入一维数组即可 内部会根据pageNum进行调整 )。
- **响应式设计**：根据屏幕尺寸的不同，可能需要调整 `heightNum` 和 `pageNum` 以适应不同的设备。
- **性能优化**：如果 `list` 数据量较大，建议使用虚拟滚动或其他性能优化技术来提升用户体验。
- **样式定制**：可以通过修改 `indicatorActiveColor` 来改变指示器的颜色，也可以通过自定义样式来调整组件的外观。
